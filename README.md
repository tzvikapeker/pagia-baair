# פגיה בעיר 🛍️

רשת חברתית-שוק לשני סוגי מודעות:
- **פגיה** — מוצרים שעומדים לפוג תוקף, אנשים משתפים כדי שאחרים ייקחו.
- **סטוק בזול** — עודפי מלאי של פרטיים ועסקים במחיר מוזל.

עברית/אנגלית/רוסית/ערבית · RTL/LTR אוטומטי · רב-משתמשים אמיתי · זמן-אמת.

---

## הרצה

```
cd C:\dev\pagia-baair
npm install        # פעם ראשונה בלבד (Electron)
npm start
```

או בלי Electron: פתיחת `index.html` ישירות בדפדפן (הכול vanilla, אין build).

## ארכיטקטורה בקצרה

```
מחשב המשתמש                         ענן Supabase
┌──────────────────────┐            ┌─────────────────────┐
│ index.html  (שלד)    │  פרסום →   │ posts        (מודעות)│
│ app.js      (ליבה)   │            │ chat_messages (צ'אט) │
│ i18n.js     (4 שפות) │  ← עדכון   │ storage      (מדיה)  │
│ settings.js (זהות)   │     חי     │ realtime     (שידור) │
│ feed-extras (פיד ∞)  │            └─────────────────────┘
│ backend.js  (הגשר)   │                     ↕
└──────────────────────┘             משתמשים אחרים
```

## הקבצים

| קובץ | תפקיד |

| `index.html` | שלד ה-SPA: ניווט, פיד, גלה, שמורים, צ'אט, פרופיל, מודלים |
| `app.js` | הליבה: state, רינדור כרטיסים, פיד כפול, צ'אט UI, התראות, פרופיל |

| `settings.js` | הגדרות משתמש: שם (זהות), עיר, שכונות/אזורים, זיהוי GPS/IP, סינון התראות |
| `feed-extras.js` | פיד אינסופי + גנרטור פוסטי-דמו |
| `backend.js` | כל התקשורת עם Supabase: טעינה, פרסום, צ'אט, נוכחות, הקלדה, נקרא |
| `config.js` | מפתחות Supabase (URL + publishable key) |
| `supabase-schema.sql` | סכמת ה-DB המלאה (posts, chat_messages, RLS, storage, realtime) |
| `style.css` | כל העיצוב, כולל שכבות ה-flat/realistic והצ'אט |

| `checkpoint.ps1` | גיבוי ZIP עם חותמת זמן: `.\checkpoint.ps1` |

## מה עובד היום (R21)

**פיד** — שני פידים נפרדים (פגיה/סטוק), composer בסגנון פייסבוק, פיד אינסופי,
העלאת תמונה/וידאו, כרטיסים עם תג תפוגה/הנחה, חיפוש, סינון עיר/קטגוריה/תגית.

**רב-משתמשים (Supabase)** — כל פרסום נשמר ב-DB ומופיע אצל כולם מיידית (Realtime).
מדיה נשמרת ב-Storage. פתוח בלי הרשמה (RLS: קריאה+הוספה בלבד).

**צ'אט אמיתי** — חדר לכל מודעה; היסטוריה נשמרת; "מקליד עכשיו"; אישורי קריאה
(סימון בודד/כפול); נוכחות "מחובר עכשיו / נראה לאחרונה"; כרטיס המוצר מוצמד לשיחה;
מובייל: פאנל אחד + כפתור חזרה. אין בוט — עונים רק משתמשים אמיתיים.

**התראות לפי מיקום** — בהגדרות (⚙️): שם, עיר, שכונות/אזורים, זיהוי מיקום
אוטומטי (GPS → נפילה ל-IP), ומתג "התראות רק מהאזור שלי". התראה מגיעה רק אם
מיקום הפוסט מכיל את העיר/אזור שלך. הפיד לא מסונן — רק ההתראות.

**4 שפות** — עברית (ברירת מחדל), אנגלית, רוסית, ערבית. מתג בסרגל העליון,
הכיוון מתהפך אוטומטית, הבחירה נשמרת.

## חשבון Supabase

פרויקט: `pagia-baair` · המפתחות ב-`config.js` · הסכמה כבר הורצה (posts + chat_messages).
להקמה מחדש מאפס: `SETUP_SUPABASE.md`.

## מה עוד לא קיים (הכנות לפרודקשן)

מחיקה/עריכה של פוסט, דיווח/חסימה נגד ספאם, rate-limiting, לייקים/תגובות
מסונכרנים ל-DB, מונה שיחות אמיתי בסרגל, ומפרידי-תאריך בצ'אט.

## תיעוד נוסף

- `CHANGELOG.md` — כל היסטוריית הגרסאות R1–R21, מה נוסף בכל שלב ולמה.
- `VISION.md` — חזון, חוקי הברזל (Iron Rules), roadmap.
- `BACKEND_PLAN.md` — שיקולי הארכיטקטורה שהובילו ל-Supabase.
- `SETUP_SUPABASE.md` — הקמת ה-backend מאפס.
- `CHECKPOINT.md` — מצב הפרויקט + איך לשחזר.
